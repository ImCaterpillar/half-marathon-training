# 专项训练总方案结构化说明

本项目的 seed 数据已接入上传文件 `deep-research-report.md` 中的训练规划。

## 已写入数据库的数据

- `training_phases`：7 个年度训练阶段。
- `workouts`：2026-05-25 至 2026-08-16 的前 12 周逐日训练，共 84 条。
- `plan_versions`：记录 seed 来源、阶段数量、训练数量和每周目标跑量摘要。

## 日期规则

默认 seed 起点固定为：

```bash
2026-05-25
```

这与方案中的“从 2026-05-25 当周起算”保持一致。若需要整体平移计划，可设置：

```bash
SEED_START_DATE=YYYY-MM-DD pnpm seed
```

## 距离字段转换规则

原方案多处以“时间优先”表达训练，例如 30 分钟、75 分钟、4×5 分钟等。由于数据库 `workouts.planned_distance_km` 需要数值，本项目采用以下规则结构化：

1. 每周使用原方案目标跑量区间的中值。
2. 对当周跑步训练按训练时长和训练类型分配计划距离。
3. 休息、活动度、单车、椭圆机、快走等非跑步训练距离为 0。
4. 原始“距离或时间”“配速/RPE”“力量安排”“注意事项”完整保留在 `main_set` 和 `notes` 中。

## 安全说明

如果你已经在正式库产生了打卡记录，不建议直接清空旧计划。测试库中如需替换同一窗口内未完成、未跳过且无打卡日志的旧计划，可运行：

```bash
SEED_REPLACE_EXISTING_PLAN=true pnpm seed
```

正式环境建议先使用 `/versions` 导出 JSON 完整备份。
